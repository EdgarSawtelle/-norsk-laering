Export to Anki

The export uses the filtered entries. Copy the text, save it as a .txt file, and in Anki choose File → Import. The header lines set the separator (tab), turn on HTML and put the tags in column 3.

The app reads norsk-database.md from the project. Claude updates the copy inside the app after each lesson. If you have a newer version, paste the whole markdown here: it's saved in this browser only.
